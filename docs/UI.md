# 画面の原則：表示を切り替えても操作の位置を変えない

使っていて困っていること：

- フォントの「見本」から「リスト」へ切り替えると、見本の文字の行が消えてツールバーが 1 行縮み、下の操作がガクッと上がる
- グループ分けで「ファミリー」を選んだときだけ「まとめる／並べる」が出て、ほかを選ぶと消える。押そうとした場所に無い
- 開いている表示（ゴミ箱、重複の候補、スマートフォルダ、フォルダ）によって 2 段目の項目が増減し、「評価」の星の位置が毎回変わる

位置が変わると、手が覚えた場所を毎回探し直すことになる。よく使う操作ほど困る。

## 原則

表示（ビュー・モード・レイアウト・選択の有無・グループ分け）を切り替えても、ツールバーやパネルにある操作の **位置と大きさを変えない**。

| 場面 | どうするか |
|---|---|
| どの表示でも使う操作 | 常に同じ位置に出す。その表示で使えないときは消さずに **無効表示** にし、理由をツールチップに書く |
| ある選択の中の下位の選択肢 | 上位の選択によって出したり消したりしない。少なければ 1 つのセグメントに並べ、多ければメニューにまとめる |
| その表示だけの操作（ゴミ箱を空にする、まとめて整理、しきい値など） | 「この表示の操作」の置き場所を **1 か所** 決めてそこに置く。中身が無いときも、その場所の位置と高さは変えない |
| ラベルが変わるボタン（並び順、グループ分け、パターン） | 幅を固定し、長いラベルは省略する。隣の操作を押し出さない |
| 入力欄の中の × などの小さなボタン | 使えないときは隠してよいが、場所は空けておく（`visibility: hidden`） |

**例外**：利用者が自分で開け閉めするもの（サイドバー、詳細パネル、シェルフ、絞り込みバー）は動いてよい。ただし開け閉めは、その操作をしたときにだけ起こす。別の操作の結果として勝手に開かない。

内容（一覧の行、件数、見出し）が変わるのはかまわない。この原則が対象にするのは **操作の場所** だけ。

## 今のずれている箇所

直すときの対象。上から影響の大きい順。

| 箇所 | 今の動き | 直し方 |
|---|---|---|
| 見本の文字の行（`src/components/Toolbar.tsx` の `SpecimenControls`、301 行目） | 見本レイアウトのときだけ出る | フォントモードではどのレイアウトでも出す。入力した文字はリストとグリッドにも使う |
| サムネイルの大きさ（同 `ThumbSize`、414 行目） | 見本とリストで消え、右端の操作がずれる | 見本の文字の行の右端に寄せ、レイアウトに応じて「文字の大きさ」「タイルの大きさ」として同じ場所に置く |
| グループ分け（`src/components/ViewMenu.tsx` の `GroupMenu`、165 行目） | ボタンのラベルが「グループ」〜「ファミリー（1件にまとめる）」で伸び縮みし、右の操作を押し出す | セグメント［なし｜まとめる｜ファミリー別｜評価｜タグ｜フォルダ］にする。ファミリーの 2 つを上位の選択で出し入れしない |
| 2 段目の左側（`Toolbar.tsx` 303〜375 行目） | 条件、サブフォルダ、種類、重複のしきい値、並べ替えの案内、書き出しが表示ごとに増減し、「評価」の位置が変わる | 「評価」と「種類」を左端に固定する。表示ごとの項目は「この表示の操作」の場所へ移す |
| 1 段目右の操作（`Toolbar.tsx` 241〜296 行目） | 表示によって「追加」「ゴミ箱を空にする」「まとめて整理」「まとめて出力・空にする」と入れ替わり、幅が変わって検索欄が伸び縮みする | 「この表示の操作」の場所として幅を固定する |
| 並び順のラベル（`Toolbar.tsx` 388 行目） | 「手動」と「追加日」などで幅が変わる | 幅を固定する |
| 種類の切り替え（`Toolbar.tsx` の `KindFilter`、455 行目） | 重複の候補では消える | 無効表示にする（重複の候補は画像だけが対象、とツールチップに書く） |
| 検索欄の ×（`Toolbar.tsx` 220 行目） | 文字があるときだけ出る | 場所は空けておく |
| 絞り込み条件の行（`Toolbar.tsx` 418 行目、`ActiveFilters`） | 条件を付けると一覧の上に 1 行増える | 検討中。絞り込みバー（自分で開くもの）の中に収めるか、行の高さを常に取るか |

サイドバーの項目がモードで違う（フォントモードでは「重複の候補」が無く、「言語・書体・太さ・特徴」がある）のは、モードが別の一覧なので対象外とする。並び順だけはモード間でそろえる。

## 決めたこと

| 論点 | 決定 |
|---|---|
| 「まとめる／並べる」の置き方 | グループ分けのセグメントに 2 つとも入れる：［なし｜まとめる｜ファミリー別｜評価｜タグ｜フォルダ］ |
| 表示ごとに変わる操作 | どの表示でも使う操作は固定（使えないときは無効表示）。その表示だけの操作は「この表示の操作」の場所 1 か所にまとめる |

この原則は desktop-platform の [UI Standard](https://github.com/jazmf-dx/desktop-platform/blob/main/standards/ui.md) にも載せる（stockroom で直したら、そちらの「出どころ」をこのファイルから実装へ差し替える）。
