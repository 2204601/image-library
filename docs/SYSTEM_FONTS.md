# この端末のフォント

デザインの見本を作るときは、ライブラリに入れたフォントだけでなく、この端末にインストールされているフォント（OS に付いているもの、
自分で入れたもの）とも比べたい。別アプリ（font-preview。ブラウザの Local Font Access API で端末のフォントを並べる）で
見ていたものを、フォントモードの中で見られるようにする。

問題は、端末のフォントが **アセットではない** こと。ライブラリのフォントは自分で取り込み、評価・タグ・フォルダで整理し、
書き出し・共有・別のライブラリへのコピーができる。端末のフォントは OS やアプリのインストールで増えたり減ったりし、
別の端末には無く、OS に付いているものはその端末で使う前提のライセンスになっている。

## 決定（2026-10-17。フェーズ 2・3 も同じ日）

| 論点 | 決定 |
|---|---|
| 区切り方 | **データはライブラリに入れず、画面ではライブラリのフォントと同じ形で並べる**。境界はデータの層に置き、画面の層には置かない |
| 置き場所 | フォントモードのサイドバーの「見るもの」に **「この端末のフォント」**。読み取り専用の一覧（仮想の一覧） |
| 使えること | 見本・グリッド・ビューア・詳細パネル、見本の文字・パターン、言語・書体・太さ・特徴の絞り込み、名前の検索、書体・言語のグループ分け、Finder / エクスプローラで表示、**シェルフ・比較**（フェーズ 2） |
| 使えないこと | 評価・タグ・フォルダ・メモ・お気に入り・ピン留め・ゴミ箱・名前の変更・書き出し・別のライブラリへ。**消さずに無効表示**にし、理由をツールチップに書く（[UI.md](UI.md)） |
| 評価・タグ | 付けない。必要になったら、PostScript 名をキーにした別の表で後から足す |
| ライブラリに取り込む（フェーズ 4） | **やらない**。OS に付いているフォントをライブラリにコピーすると、共有（LAN）・書き出し・別のライブラリへのコピーで外に出せてしまう。見直すとしても、自分で入れたフォント（`~/Library/Fonts` など）だけにする |
| 対象 | OS のフォントフォルダにあるもの（下の「読むフォルダ」）。**Adobe Fonts などアプリが自分の場所に置くフォントは対象外** |
| シェルフ・比較（フェーズ 2） | 端末のフォントもフォントのシェルフに置け、ライブラリのフォントと **1 つの並び** で比較に並ぶ（最大 8 件は合わせて数える）。シェルフはライブラリのものなので、別の端末で開いてそのフォントが無ければ、名前だけを取り消し線で出す（比較では「この端末にインストールされていないフォント」） |
| ライブラリとつなぐ印（フェーズ 3） | **PostScript 名** が同じものを同じフォントとする。ライブラリのフォントに「インストール済み」、端末のフォントに「ライブラリにある」。詳細パネルにも「この端末」「ライブラリ」の行 |
| font-preview | Stockroom から参照しない（コードは持ってこない）。Web 版を残すかは Stockroom の作りに影響しない |

ブラウザの `queryLocalFonts` は使わない。macOS の WKWebView は対応しておらず、取れるのは名前だけで、
見本・文字の有無・書体の分類にはフォントの中身が要るため。

## 読むフォルダ

`fontdb`（resvg が SVG の文字を描くのに使っているもの）の `load_system_fonts` が読むフォルダと同じ。

- macOS：`/System/Library/Fonts`、`/Library/Fonts`、`~/Library/Fonts`、`/Network/Library/Fonts`、
  あとから入れたシステムフォント（`/System/Library/AssetsV2/com_apple_MobileAsset_Font*`）
- Windows：`C:\Windows\Fonts`、`%LOCALAPPDATA%\Microsoft\Windows\Fonts`（ユーザーごとのフォント）
- Linux（開発用）：fontconfig の設定にあるフォルダ

形式はライブラリと同じ（TTF / OTF / WOFF / WOFF2 / TTC / OTC）。TTC / OTC は **1 ファイル = 1 件**（ライブラリと同じ）。
256 MB を超えるファイルは読まない。

## 作り

- Rust：`src-tauri/src/fonts/system.rs`
  - `list`：フォントのフォルダを読み、ファイルごとにライブラリと同じ `fonts::meta`（ファミリー・太さ・言語・書体・特徴）と、
    最初のフォントのフルネーム（一覧の名前）を取る。結果はアプリのキャッシュフォルダの `system-fonts.json` に置き、
    パス・大きさ・更新日時が同じファイルは読み直さない。1 回の起動で 1 回だけ読み、「読み込み直す」でフォルダを読み直す
  - ID は `sys:` と **PostScript 名** のハッシュ（`assign_ids`）。別の端末でも同じフォントなら同じ ID になるので、シェルフに置いたものを
    そこでも見つけられる。同じ名前のファイルが 2 つあれば（手で入れた別の版など）パスの順で 2 つ目以降を分け、名前の無いものはパスで作る
  - **フロントエンドからはパスを受け取らない**。ID は直前に読んだ一覧から引き、そこにあるファイルだけを読む
  - フォントの中身は、ライブラリのフォントと同じコマンド（`font_data` / `font_info` / `font_faces` / `font_list_preview`）で返す。
    `fonts/commands.rs` の `font_sfnt` が `sys:` の ID を `system::sfnt` へ振り分ける
  - 足したコマンドは `system_fonts(reload)`（一覧）と `reveal_system_font(id)`（Finder / エクスプローラで表示）だけ。
    アプリのコマンドなので capabilities と CSP は変えていない
- フロントエンド：`src/features/fonts/system.ts`
  - 一覧の 1 件を `Item` の形にする（`kind: "font"`、ID は `sys:…`、評価・タグなどは空、`importedAt` はファイルの更新日時）。
    見本の行・グリッド・ビューア・詳細パネルの行（`FontDetails`）はそのまま使う。書体は自動の判定を出すだけで、変えられない
  - 絞り込み・検索・並べ替えは、SQL（`db.rs` の `query_where`）ではなくここで行う。件数は数百〜数千なので足りる。
    絞り込みの行のメニューの件数（`facet_counts` の代わり）もここで数える
    - 検索：名前・ファミリー名・ファイル名に、空白で区切った語をすべて含むもの。`-語` は除外、`"語句"` はひとまとまり。
      ライブラリの検索の OR と括弧は使えない（ただの語として探す）
    - 並び順：追加日（＝ファイルの更新日時）・名前・ファイルサイズ。評価は選べない（無効表示）。手動は名前順になる
  - 場所は `View` の `{ kind: "system" }`。Rust には送らない（`store.ts` の `refresh` と `FilterRow.tsx` の `useFacets` で振り分ける）
  - 詳細パネルは `SystemFontPanel.tsx`（見本の文字・行・場所・更新日と、読み取り専用である旨）。ビューアの詳細も評価・タグの代わりに同じ旨を出す
- ライブラリの ID を受けるコマンドへ `sys:` の ID を渡さない
  - `commands.ts`：選択に端末のフォントがあれば書き込み・コピー・既定のアプリで開く・名前の変更・ゴミ箱を無効にする（`mine`）。
    一覧を対象にする書き出し・まとめて出力・別のライブラリへ・シェルフにすべて追加・新しいスマートフォルダは、この一覧では無効（`library`）
  - `actions.ts`：各操作の入口で `libraryIds` で外す（数字キーの評価、ビューアのキーなど、表を通らない呼び出しの守り）
  - 一覧：ドラッグを始めない（フォルダ・シェルフへ入れない、ファイルとしてアプリの外へ出さない）。右クリックは「表示」「Finder で表示」だけ。
    お気に入り・シェルフのボタンは出さない
  - ツールバー・絞り込みの行・グループ分け：「追加」の場所に「読み込み直す」。評価・タグ・追加日の条件、［評価｜タグ｜フォルダ］のグループ分け、
    「条件を保存」は無効表示にして、理由をツールチップに書く（評価・タグ・フォルダのグループ分けを選んでいたら、この一覧ではグループ分けなしで出す）
- 開発用のモック（`src/dev/mockBackend.ts`）にも、端末のフォントを 8 件と、別の端末でシェルフに置いた（ここには無い）1 件を入れた

### フェーズ 2：シェルフ・比較

- DB：`tray_system(id, name, position)`（step 23）。`tray` は `items` を参照する（`REFERENCES items(id)`）ので別の表にし、
  `position` を `tray` と共有して 1 つの並びにする（`db.rs` の `tray_order`）。`name` はその端末に無いときに出す名前
  - 置く：`add_system_to_tray`（`fonts/commands.rs`。名前は一覧から引く）。外す・並べ替え・空にするは、ライブラリの項目と同じ
    `remove_from_tray` / `reorder_tray` / `clear_tray` が両方の表を見る
  - 数（`Counts.tray`）はライブラリの項目だけ
- フロント：`store.ts` の `refresh` で、フォントモードのシェルフ（ライブラリの項目）に `fontShelf`（`system.ts`）が端末のフォントを
  `system_tray` の並びで差し込む。一覧に無い ID（その端末に無いフォント）は `unavailable` の印を付けた名前だけの行にする
  - `actions.ts` の `addToTray` は ID を分けて、ライブラリの項目は `add_to_tray`、端末のフォントは `add_system_to_tray` へ（取り消しも同じ）
  - シェルフの中身を対象にする「別のライブラリへ」は端末のフォントを外す
  - 操作：B キー・シェルフのボタン・右クリック・詳細パネルの「シェルフに追加」・ドラッグ。**ドラッグはシェルフへだけ**
    （フォルダ・一覧の並べ替えの上では落とせず、窓の外へファイルとして出さない。`DragLayer.tsx`）
  - 比較（`CompareView.tsx`）：端末のフォントは、太さの選択肢を端末のフォントの同じファミリーから出す。評価・お気に入りの代わりに
    「この端末のフォント」と出す。シェルフのチップは名前の前に画面の印
  - その端末に無いフォントは、シェルフでは取り消し線、比較では名前と「この端末にインストールされていないフォント」。外すことはできる。
    外したのを取り消しても戻らない（名前しか無いため）

### フェーズ 3：ライブラリとつなぐ印

- PostScript 名（最初のフォントのもの。`fonts::meta` の `ps_name`）を、ライブラリの項目は `items.font_ps_name`（step 23）に持つ。
  前からあるフォントは、step 23 で読み直しの印（`font_features = NULL`）を付け、開いたときの `index_fonts` で読み直す
- フロント：`system.ts` の `useFontLinks`（端末のフォントとライブラリのフォント、それぞれの PostScript 名の集合）。
  フォントモードの `refresh` ごとに `refreshFontLinks` で取り直す。端末のフォントの一覧は **フォントモードを開いたときに裏で読む**
  （初めての端末では時間がかかるが、一覧は待たせない。読めたらサイドバーの件数も出る）
- 印（`FontLink.tsx`）：見本の行に「インストール済み」「ライブラリにある」、グリッドのタイルの左下にアイコン、詳細パネルに「この端末」「ライブラリ」の行。
  ファミリーの行は代表（Regular）の印で、▸ で開いた太さ違いはそれぞれの印
