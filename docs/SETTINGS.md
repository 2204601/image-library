# 設定画面とライブラリごとの設定

使っていて困っていること：

- モード（画像／フォント）がアプリ全体で 1 つなので、ライブラリを切り替えてもモードが前のまま。
  画像のライブラリは画像モード、フォントのライブラリはフォントモードで開きたい
- サイドバーの固定項目（お気に入り・ピン留め・作業台など）は、ライブラリによっては使わない。ライブラリごとに隠したい

あわせて、あちこちに散っている設定（ブラウザ拡張の連携、アップデートの確認）を 1 つの設定画面にまとめる。

## 決定

| 論点 | 決定 |
|---|---|
| ライブラリごとのモード | **最後に開いていたモードを自動で記憶する** ＋ 設定で **使う種類** を選べる（1 種類ならモード切替を隠す） |
| サイドバーで隠した項目 | **表示だけ隠す**。B キーで作業台へ追加などの操作はそのまま使える |
| ライブラリごとの設定の保存先 | **`library.db`**。ライブラリのフォルダごと持ち運べば設定も付いてくる |

## 設定の置き場所（3 層）

| 層 | 保存先 | 中身 |
|---|---|---|
| アプリ全体 | `settings.json`（`app_config_dir`、`commands.rs` の `Settings`） | 起動時に開くライブラリ、アップデートの自動確認、ブラウザ拡張、ライブラリ一覧 |
| ライブラリごと | `<name>.library/library.db` の `settings` テーブル（新規） | 使う種類、最後に開いていたモード、サイドバーで隠す項目 |
| 表示の好み | `localStorage`（今のまま） | レイアウト・グループ分け（モードごと）、サムネイルの大きさ、パネルの開閉など |

表示の好みはライブラリに付けない（どのライブラリでも同じ見た目のほうが迷わない）。
ライブラリに付けたくなったものだけ、あとから `settings` テーブルへ移す。

共有フォルダに置いたライブラリを複数人で使う場合、ライブラリごとの設定は全員に効く。
「このライブラリはフォント用」という性質の設定なので、それでよいと判断した。

## ライブラリごとの設定

### データ

`library.db` に追加する。他のテーブルと同じく `CREATE TABLE IF NOT EXISTS` で作る（作業台の `tray` と同じやり方）。

```sql
CREATE TABLE IF NOT EXISTS settings (
  key   TEXT PRIMARY KEY,
  value TEXT NOT NULL  -- JSON
);
```

| key | value | 無いとき |
|---|---|---|
| `modes` | 使う種類 `["image","font"]` | すべての種類（`MODES`） |
| `lastMode` | 最後に開いていたモード `"font"` | 下の「開くときのモード」で決める |
| `hidden:<mode>` | そのモードのサイドバーで隠す項目 `["pinned","tray"]` | 何も隠さない |

- 値は JSON。項目を増やしても列を足さずに済む
- 知らないキーや、知らない種類・項目の ID は読み飛ばす（古い版で開いても壊れない）
- コマンド：`get_library_settings() -> { [key]: JSON }`、`set_library_setting(key, value)`。
  `value` が `null` ならその行を消す

フロントエンドは `setLibrary` でライブラリを開くときに読み込み、`store` に `librarySettings` として持つ。

### 使う種類とモード

**開くときのモード**（`setLibrary` で決める）

1. `lastMode` があって、使う種類に入っていればそれ
2. 無ければ、使う種類のうち件数（`Counts.kinds`）が最も多いもの
3. どれも 0 件なら、使う種類の先頭

今ある `localStorage` の `mode` キーは使わなくなる（ライブラリを開いていないときのウェルカム画面ではモードを使わない）。

**モードを切り替えたとき**：`setMode` で `lastMode` を保存する。

**モード切替（`ModeSwitch`）**

- 使う種類だけを並べる。1 種類だけならモード切替ごと隠す
- ショートカット ⌘1〜⌘3 は `MODES` の並びのまま固定（⌘3 はいつもファイル）。使っていない種類のキーは何もしない

**使っていない種類のファイルを取り込んだとき**

取り込みは止めない（種類は中身で決まる）。取り込み後のトーストで知らせる：

> フォント 3 件を取り込みました。このライブラリでは使っていない種類です。［フォントも使う］

ライブラリ間のコピー・移動（`transfer.rs`）でも、コピー先で使っていない種類があれば同じように知らせる。

**使う種類から外したとき**

その種類のアイテムは消さない。件数が 1 件以上あれば、設定画面のチェックの横に「（123 件）」と出し、
外すときに「一覧に出なくなります。アイテムは消えません」と添える。

### サイドバーの項目

モードごとに隠せる（画像モードではピン留めを使い、フォントモードでは使わない、といった使い分けができる）。

| ID | 項目 | 隠せるか | 備考 |
|---|---|---|---|
| `all` | すべて | × | 開いたときの表示先 |
| `unfiled` | 未分類 | ○ | |
| `untagged` | タグなし | ○ | |
| `favorites` | お気に入り | ○ | |
| `pinned` | ピン留め | ○ | |
| `tray` | 作業台 | ○ | |
| `similar` | 重複の候補 | ○ | 画像モードのみ |
| `trash` | ゴミ箱 | × | 削除したものの行き先が見えなくなるため |
| `section:folders` | フォルダ（節ごと） | ○ | |
| `section:smart` | スマートフォルダ（節ごと） | ○ | |
| `section:tags` | タグ（節ごと） | ○ | |
| `section:fontFilters` | 言語・書体（節ごと） | ○ | フォントモードのみ |

ファイルモード（`feat/file-mode`）で節が増えたら、ここに ID を足す。

**隠し方・戻し方**

- 項目または節の見出しを右クリック →「サイドバーから隠す」
- 設定画面の「このライブラリ」にチェックリストを置き、そこで戻す（隠すのもここでできる）
- 何か隠しているときは、サイドバーの一番下に小さく「n 項目を非表示（表示…）」を出す。
  押すと設定画面のその場所を開く。隠したことを忘れて「作業台が消えた」とならないようにする

**隠した項目の振る舞い（表示だけ隠す）**

- 機能はそのまま：B キーで作業台へ追加、お気に入りやピン留めの切り替え、件数の集計（`get_counts`）は今までどおり
- いま開いている表示を隠したら「すべて」へ移る
- 隠した表示へ追加したときは、トーストに［作業台を開く］などを付けて、その表示へ行けるようにする
- 「フォルダ」の節を隠しても、フォルダ選び（Shift+D、`FolderPicker`）は使える

## 設定画面

- ⌘, で開くモーダル。入口はライブラリメニューの「設定…」と、macOS のアプリメニューの「設定…」
  （アプリメニューからは「アップデートを確認」と同じくイベント経由で開く）
- 左にタブ、右に中身。変更はその場で保存する（「保存」ボタンは置かない）

### 一般（アプリ全体）

- 起動時：前回のライブラリを開く／ライブラリを選ぶ（`settings.json` に `startup: "last" | "choose"`）
- アップデートを自動で確認する（`autoUpdate: bool`、初期値オン）。オフなら `scheduleUpdateCheck` を動かさない
- バージョン表示と「アップデートを確認…」ボタン（ライブラリメニューから移す）

### このライブラリ

- ライブラリの名前と場所（「Finder で表示」）、件数と容量
- 使う種類（チェックボックス。最低 1 つ。各種類の件数を添える）
- サイドバーの項目：使う種類ごとに、上の表の項目をチェックボックスで

### 連携

- 今の「ブラウザ拡張と連携…」ダイアログの中身をここへ移す

### ライブラリメニュー（サイドバー上部）

ライブラリの一覧・「ほかのライブラリを開く…」「新しいライブラリを作成…」と「設定…」だけにする。
ブラウザ拡張は「連携」、アップデートの確認は「一般」、「<種類>をすべて別のライブラリへ移す…」は「このライブラリ」へ移した
（メニューバーの「ファイル」にも置く。MENUS.md）

## 後で足す候補（今回は作らない）

- ゴミ箱の自動削除（n 日たったら完全に削除）：ライブラリごと
- フォント見本の既定の文字と大きさ：今は `localStorage`。ライブラリごとに変えたくなったら移す
- 一括エクスポートのプリセット（ロードマップのフェーズ 3）：アプリ全体
- 取り込みの既定（取り込み時に付けるタグ、保存先フォルダ）：ライブラリごと
- 外観（ライト／ダーク）：今はダークのみ

## 実装の順番

すべて実装済み（1〜7）。`src/lib/librarySettings.ts`（読み込み・開くときのモード・サイドバーの項目の一覧）、
`components/SettingsDialog.tsx`、`db.rs` の `library_settings` / `set_library_setting` / `used_kinds`。

1. `settings` テーブルと `get_library_settings` / `set_library_setting`（`db.rs`、`commands.rs`）、テスト
2. `store` に `librarySettings`。`setLibrary` で開くときのモードを決め、`setMode` で `lastMode` を保存
3. `ModeSwitch` を使う種類だけに。⌘1〜⌘3 で使っていない種類を無視
4. サイドバーの非表示（右クリック、`hidden:<mode>`、下部の「n 項目を非表示」）
5. 設定画面（一般・このライブラリ・連携）。ブラウザ拡張のダイアログとアップデート確認を移す
6. 取り込み・ライブラリ間コピーで、使っていない種類を知らせるトースト
7. `ARCHITECTURE.md` の「モード」の節を更新（モードはライブラリごとに記憶）

## 他の作業との関係

- **ファイルモード（`feat/file-mode`）**：`MODES` に `"file"` を足す。DB のマイグレーションは無く、
  サイドバーの固定項目（`Sidebar` の `smart`）も触らない、と確認済み。こちらは種類を 2 つと決め打ちせず
  `MODES` の配列で扱う。⌘1〜⌘3 の一般化（`MODES[index]`）は向こうで入るので、使っていない種類を無視する条件だけ足す。
  向こうが先に main に入る見込みなので、実装はその後に main から始める
